Claude Code is Anthropic's terminal-based agentic coding assistant. The LYF x AI workshop teaches you to use it effectively — from setup to real-world projects. Whether you're a seasoned developer or just getting started, you'll leave with practical skills and confidence to integrate AI into your daily coding workflow.

## What Is Claude Code?

Claude Code is a CLI tool built by Anthropic that brings Claude's AI capabilities directly into your development workflow. Unlike a chatbot you paste code into, Claude Code lives in your terminal and operates alongside your project. It can read your entire codebase, write and edit files, run shell commands, and iterate autonomously until a task is complete — all without you switching context away from your editor.

Think of it less as an autocomplete tool and more as a highly capable AI collaborator that understands your project from the inside out.

## Workshop Format

The Claude Code workshop is a **2–3 hour live session** that blends instruction, live demos, and hands-on exercises. You'll spend the first portion learning the concepts, then immediately apply them in guided exercises — so you're coding with AI assistance within the first 30 minutes.

The workshop is available in both **in-person** and **online** formats. For online sessions, you'll need a working development environment set up in advance. All exercises are self-contained and don't require any specific project or codebase.

<Info>
  Bring a project you're actually working on. Many attendees find the exercises more valuable when applied to real code rather than toy examples.
</Info>
